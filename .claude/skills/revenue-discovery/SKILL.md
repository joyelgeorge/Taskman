# Revenue Discovery: Unfiltered Opportunity Exploration

This skill explores, surfaces, and catalogs monetization opportunities across software, data, agent services, micro-products, and developer ecosystems.

## Exploration Directive
1. **Never filter prematurely**: Do not discard an idea because it is unproven, weird, or small. Every opportunity is logged as a testable hypothesis.
2. **Surface Multiple Monetization Archetypes**:
   - **Micro-SaaS & Self-Hosted Tools**: One-time license, API credits, pay-per-report (like the Payout Auditor).
   - **Data & Signal Feeds**: Curated datasets, niche API feeds, trend alerts, compliance lists.
   - **Agent Automation Services**: Lead gen automation, invoice & receipt extraction, customer support bots, data scraping pipes.
   - **Bounties & Competitions**: Open-source bounties, security bug bounties (HackerOne, Bugcrowd, Immunefi), AI benchmarks, Kaggle prizes.
   - **Digital Goods & Developer Assets**: CLI utilities, starter templates, pre-trained adapters, UI kits.
   - **Affiliate & Referral Bridges**: High-ticket developer tools, cloud hosting referrals, infrastructure credits.

## Opportunity Evaluation Framework
For every discovered opportunity, analyze across 4 dimensions:
1. **Time-to-First-Dollar**: Can this earn within 24 hours, 1 week, or 1 month?
2. **Capital & Account Requirements**: Does it require Stripe, PayPal, crypto wallet, or KYC?
3. **Distribution Angle**: Where are buyers already looking for this right now (Reddit, HackerNews, X, GitHub, Upwork, Discord)?
4. **Feasibility**: Can existing Taskman code, drones, or LLMs fulfill this autonomously?

## Output Structure
When asked to explore revenue, output:
- **Opportunity Title & Mechanism**
- **Buyer Persona & Urgent Pain Point**
- **Monetization Mechanics (Price point & payment rail)**
- **Fastest Prototype Experiment (How to test demand with 0 code or in <2 hours)**
