# Parked tasks

Work that was found but deliberately not done, so it can be picked up later
instead of blocking whoever found it.

Write one here when:

- **Another session is mid-edit in the same file.** Two sessions share this
  working tree. If you need to change something that is currently uncommitted
  and half-finished by someone else, do not touch it and do not wait — park the
  task and carry on.
- **You found a real problem outside the job you are doing.** Fixing it would
  widen the change past what a reviewer can judge in one sitting.
- **A change needs a decision that is not yours** — pricing, outreach, anything
  that spends money or contacts a person.

One file per task, named `YYYY-MM-DD-short-slug.md`. Say what you found, where
it is, why it was not done now, and what "done" would look like. Enough that
someone picking it up cold does not have to re-derive it.

Delete the file in the commit that completes the task; a parked task that is
silently done is a task someone will do twice.
