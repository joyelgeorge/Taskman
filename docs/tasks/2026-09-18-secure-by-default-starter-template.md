# "Secure-by-default" Supabase/Next.js starter template

Raised from a `/revenue-discovery` pass, 2026-09-18. Scored **0.65**.

## The idea

A GitHub template repo with RLS policies, auth guards, and no
service-role-key-in-client baked in from `git init` — the exact fixes
`findMissingRls` / `findSupabaseTableMissingRls` / `findUnauthenticatedAdminRoutes`
already recommend, pre-applied instead of found-after-the-fact. The vaccine
next to the cure the rest of this project sells.

`distribution: findable` (GitHub template search, "awesome-supabase" style
lists — no marketplace, no existing relationship). `saturation: underserved`
— no direct "secure vibe-coding starter" competitor found in this session's
research, though not exhaustively searched.

## Fulfilment is unusually cheap

It's a repository, not a service — no ongoing agent work once published,
unlike every other lane in this project's registry. That's the whole appeal
and also the whole risk: if it doesn't get found, there's no retry mechanism
built in the way outreach or a marketplace listing has one.

## Cheapest test

Publish the free version (no paywall) this week. If it gets zero stars/clones
with no promotion, that's the same answer a paid version would get, for free —
kill it before building a "Pro" tier.

## Done looks like

Free template published, at least one external clone/use (not the operator's
own), before any paid tier is built.
